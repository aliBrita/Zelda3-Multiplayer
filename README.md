# Zelda3

Multiplayer fork of the PC port of *The Legend of Zelda: A Link to the Past*.

## About

This is a fully functional multiplayer mod with LAN support and synchronized gameplay, including enemies, items, and any other game elements that need to be shared between players.

This mod was made possible thanks to the PC port available in the following repository:

https://github.com/snesrev/zelda3

## How to Play

Use a VPN service with your friend so both of you can connect to the same local network. Examples include Radmin VPN and Hamachi.

Enter the IPv4 address of the player who will host the session, then either load an existing save file or create a new one.

Controls and player skins can be changed through the launcher.

**Note:** You must provide your own original US ROM of *The Legend of Zelda: A Link to the Past*. Rename the ROM to `zelda3.sfc` and place it inside the `rom` folder.
